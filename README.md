# 📚 论文阅读站（Paper Studio）

一个**只跑在你自己的电脑上**的论文阅读辅助网站：上传论文 PDF，边读边记笔记，还能让 AI 用大白话给你讲论文。

## 功能

- 📄 **上传 PDF**：拖拽或点击选择，自动提取文字、统计页数（本地存储，不上传任何地方）
- 📖 **阅读**：浏览器内直接翻页看 PDF（缩放、跳页）
- ✨ **AI 讲解**：一键生成"新手友好讲解"——领域背景、核心贡献、方法拆解、实验结果怎么读、局限、读前问题、术语表；**生成一次自动保存**，之后打开论文直接看，想更新再点"重新生成"
- 📝 **六要素笔记**：问题 / 方法 / 实验结果 / 贡献 / 局限 / 我的想法，边读边记
- ✅ **三遍阅读进度**：①门面 ②骨架 ③血肉，勾选即自动保存
- 📖 **术语表**：每篇论文独立的术语小词典
- 💬 **问答**：随便问论文任何问题（"这个方法有什么缺点？"）；**问答记录自动保存**，下次打开论文还能看到

## 怎么启动

**推荐方式：双击桌面上的「论文阅读站」快捷方式**——它会自动启动服务并打开网站；如果服务已经在运行，直接打开网页。

```bash
# 手动方式
cd E:\workplace\paper-studio
npm start        # 或 node server.js
```

然后浏览器打开 **http://127.0.0.1:3000**

## 第一次使用：配置 AI

AI 讲解需要 DeepSeek 的 API Key（很便宜，注册送额度）：

1. 去 [platform.deepseek.com](https://platform.deepseek.com) 注册，充值几块钱就够用很久
2. 在「API Keys」页面创建一个 Key（`sk-...`）
3. 打开网站，点右上角 **⚙️ 设置**，粘贴保存

Key 只保存在本机的 `data/config.json`。不配 Key 也可以正常上传、阅读、记笔记，只是 AI 功能会提示你配置。

## 数据都放在哪

| 内容 | 位置 |
|---|---|
| PDF 原件 | `data/pdfs/` |
| 提取的纯文本 | `data/texts/` |
| 笔记 / 进度 / 术语表 | `data/notes/` |
| 论文清单 | `data/library.json` |
| API Key 配置 | `data/config.json` |

想备份就把整个 `data/` 文件夹拷走。

## 常见问题

- **上传后提示"扫描版"**：PDF 是图片扫描的，没有文字层，AI 讲不了。去论文官网/arXiv 找带文字的版本。
- **AI 报错 "API 错误 401"**：Key 不对，去设置里重新粘贴。
- **端口被占用**：`PORT=3001 npm start` 换个端口。
